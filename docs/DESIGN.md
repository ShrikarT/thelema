# Design implementation

- Category reference: https://if.market — reviewed as a conceptual reference. External browser navigation was unavailable; no visual-diff claim is made.
- Style reference: https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/design-md/vercel/DESIGN.md
- Original THELEMA wordmark/symbol and copy; no copied if.market branding, refund concept, testimonials or market history.
- Restrained monochrome surfaces, complete card borders, blue YES-world semantics, dense market data and an obvious execution-mode distinction.
- Real Noto Sans is bundled locally as a WOFF subset. Geist was unavailable; this is an explicit fallback, not a renamed claim to be Geist. Source metadata identifies Noto Project Authors; OFL notice is included.
- Phosphor icons are sourced through react-icons/pi; licenses and sources are recorded in LICENSES.
- Hero: “One event. Two possible worlds.” Primary CTA: “Open the market.”
- Separate two-line scroll-reveal tagline, with a reduced-motion path and explicit inter-word spacing.
- Four reserve-derived numbers, two-world view, reference availability, review modal, positions and real local activity.
- Keyboard focus styles, native dialog/Escape behavior, skip link, mobile navigation, semantic forms/tables, actionable errors, empty states and no fake links.
- Noindex, metadata, favicon, custom 404 and explicit research/testnet/unaudited notices. No legal policies or user claims were invented.
